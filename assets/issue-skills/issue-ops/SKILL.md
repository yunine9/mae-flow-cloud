# 网管环境操作(宿主工具)

工具在宿主侧执行,密码由平台自动带入,你不用也不会传;你只提供目标参数。部署类工具已封存(ADR-0013:当前流程不含部署环节,调用会被阶段门禁拒绝)。

## fetch_logs(services, hosts?)

- 抓 `/var/log/oss/MAE/<服务名>` 的**全部内容**(含子目录)到 `local-logs/<服务名>_<时间戳>/`;
- hosts 缺省用会话配置的网管环境;
- 大目录耗时较长属正常;完成后直接在 local-logs/ 里 grep,只读命中的报错栈与时间线段落。

## 失败处理

工具报错会带原始输出:如配置/密码/网络/服务器权限问题,如实呈现给用户,先诊断再重试。
