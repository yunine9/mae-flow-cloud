# 跨仓交付

仅当需求涉及多个代码仓时读本文件。

跨仓需求应先有链路分解文档（`/mae-flow:mae-flow chain` 的产物 `CHAIN-<单号>.md`：
各仓职责、接口契约、依赖顺序）。

- 已有 → 本仓需求文档 = 该 CHAIN 文档（+ 原需求），按其中本仓职责交付，MR 注明依赖的他仓 MR；
- 没有 → 建议用户先执行 `/mae-flow:mae-flow chain` 做链路分解再回来；用户坚持直接做则如实记录风险。

各仓地位平等、不存在主从，链路文档存放在哪个仓只是存放地。
**回流条款**：本仓交付任何阶段发现 CHAIN 文档错漏（漏触点、契约不够用、顺序不对），
停下报告用户，修订 CHAIN 文档（升版本号 + 记变更）并提醒用户同步给其他仓，
由文档先对齐再继续适配。
