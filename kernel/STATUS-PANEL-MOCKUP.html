通知发送架构

notify_service.py:16-29 - 发送入口 send(channel, notification)

  • 查找渠道处理器，未找到则返回失败
  • 重置渠道运行态（清空旧会话）
  • 为租户+渠道打开新会话（session token）
  • 调用具体渠道处理器的 send 方法

渠道处理器模式（email_handler.py、push_handler.py、webhook_handler.py）

统一的四段结构：

  1. 校验：检查必要字段（target）
  2. 渲染：文本转换（truncate 至 MAX_LENGTH=500）
  3. 发送：检查会话有效性
  4. 记账：调用 audit_log.record()

渠道运行态管理

channel_state.py

  • reset(tenant_id, channel): 清除已有会话
  • open_session(tenant_id, channel, token): 建立新会话
  • session(tenant_id, channel): 查询当前会话
  • 内部状态为内存字典 {tenant_id:channel -> token}

def load_sms_permission_config(config_path: str) -> None:
    """
    加载短信权限配置。应用启动时调用，缺失或格式错时抛异常。
    
    参数：
    - config_path: 配置文件路径（相对或绝对）

    异常：
    - ConfigError: 配置文件缺失、格式错误或内容不符合预期
    """
    global _sms_enabled_cache
    
    try:
        if not os.path.exists(config_path):
            raise ConfigError(f"SMS config not found: {config_path}")
        
        with open(config_path, 'r') as f:
            config = json.load(f)  # 可能抛 JSONDecodeError
        
        if "sms_enabled_tenants" not in config:
            raise ConfigError("Missing key: sms_enabled_tenants")
        
        _sms_enabled_cache = config.get("sms_enabled_tenants", [])
    except json.JSONDecodeError as e:
        raise ConfigError(f"Invalid JSON in SMS config: {e}")
    except ConfigError:
        raise  # 重新抛出
    except Exception as e:
        raise ConfigError(f"Failed to load SMS config: {e}")

def channel_enabled(tenant_id: str, channel: str) -> bool:
    """
    查询租户是否开通指定渠道。
    
    参数：
    - tenant_id: 租户 ID
    - channel: 渠道名称 ("sms", "email", "push", "webhook")
    
    返回：
    - True: 租户已开通该渠道

def send(channel: str, notification: Notification) -> SendResult:
    # 查找渠道处理器
    if channel not in _HANDLERS:
        return SendResult.fail(f"未注册的渠道: {channel}")
    
    handler = _HANDLERS[channel]
    
    # [新增] 短信权限检查（在会话初始化前）
    if channel == "sms":
        if not channel_enabled(notification.tenant_id, channel):
            audit_log.record(notification.tenant_id, channel, -1)  # 记录权限拒绝
            return SendResult.fail("短信: 租户未开通")
    
    # 重置会话
    channel_state.reset(notification.tenant_id, channel)
    
    # 打开会话
    token = f"tok-{len(notification.tenant_id) * SESSION_TOKEN_LENGTH}"
    channel_state.open_session(notification.tenant_id, channel, token)
    
    # [新增] 短信重试循环
    if channel == "sms":
        for attempt in range(1, 4):  # 最多 3 次
            result = handler.send(notification)
            if result.success:
                # 若非首次就成功，追加重试信息到 detail

    # [既有] 其他渠道无重试
