# 01: DTS 列表「发起状态」列——判定与拦截同尺,默认只看未发起

**What to build:** DTS 列表新增「发起状态」列(状态列之后、所属模块列之前):单子在当前登录用户名下存在进行中(非终态:未归档/未取消/未失败)的问题会话,即显示「进行中」徽标——悬停见会话 id,点击跳进该会话;未发起显示 —。「发起状态」表头漏斗给「未发起 / 已发起」两个勾选项,默认只勾「未发起」:打开列表与刷新时已发起的单默认滤掉;漏斗清空或两项全勾 = 全显。已发起的行勾选框禁用(悬停说明"已发起,进行中"),全选只作用于展示列表中可勾的行。判定与发起拦截共用同一处口径(结构性同尺:列上说"已发起"当且仅当此刻点发起会被拦);远程补查单同尺适用。纯前端:判定数据用现成的名下会话列表 prop(5 秒轮询),不动后端。
