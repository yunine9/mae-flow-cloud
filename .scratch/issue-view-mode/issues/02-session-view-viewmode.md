# 02: 工作台查看模式——非归属人只读现场、归属人照常操作

**What to build:** 团队看板的问题卡片点「进入问题工作台」或深链直达他人会话时,工作台以查看模式呈现:顶部一条「查看模式:归属人 xxx 的会话」标识,全部操作控件隐藏(续聊输入框、问题卡作答、取消/归档、绑定单号、检视、材料快速修改/解压、网管环境配置、转正等);四个信息面(概要+时间线、材料、事件流直播、耗时卡点)完整可看。归属人打开自己的会话一切照旧。前端隐藏只是体验层,后端闸在票 01 已硬保证。
