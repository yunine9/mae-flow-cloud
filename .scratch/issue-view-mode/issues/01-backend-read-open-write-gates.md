# 01: 问题会话读接口放行 + 写路由归属闸全量盘点

**What to build:** 问题会话的查看模式在 API 层成立:任何登录开发者调读接口(会话概要、时间线、材料页签的文件/diff/日志/事件、事件流 SSE)都能读到他人会话的现场;调任何写接口(续聊、问题卡作答、取消/归档、绑定单号、检视意见的记/提/移除、材料快速修改、解压日志、网管环境配置、补充插话、挂起转正)都得到明确的人话 403;归属人本人全操作不受影响;管理员保持只读(角色边界"管理员不处理问题单"不变)。整体归属闸收窄为只拦写方法,并逐接口盘点补齐仅归属人二道闸——凡此前只靠整体闸保护的写路由(预期含取消/归档)一律补上,保证"非归属人零写操作"是结构保证而非枚举自觉。
