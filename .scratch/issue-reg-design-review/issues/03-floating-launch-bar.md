# 03: DTS 列表勾选浮动发起条——长列表勾选不必滚回顶部

**What to build:** 批量发起的勾选在表格行里,主操作「发起处理」只在顶部工具栏;勾到视口之外的长列表深处时,发起与清空都要滚回顶部。勾选数大于 0 时,在表格容器之下浮出一条粘性操作条:已选 N 张 + 「发起处理」(与顶部按钮同用一套发起逻辑与 busy 禁用态)+ 「清空选择」;清空选择只清当次勾选(顶部按钮行为不变)。粘性吸底,出现与消失不做进场动画(prefers-reduced-motion 天然满足);窄屏(680px 以下)操作条全宽可用;已发起行勾选禁用、全选口径等既有行为一律不动。

**Blocked by:** None (can start immediately)
