# MAE Flow 对外架构演示

打开 `index.html` 即可离线演示，无需登录、安装依赖或连接生产服务。推荐 Windows 桌面浏览器 1920×1080，点击「全屏」。

平台入口：**使用帮助 → 顶部「40 秒看懂：从需求交付到知识复用」→ 一键播放**。新页面自动开始；「查看架构」只打开全景，不自动播放。地址为 `/help/platform-overview/index.html`，加 `?autoplay=1` 自动讲解。

## 怎么讲

- **全景架构**：一张图呈现交付闭环、知识闭环和工程能力底座。
- **交付闭环**：需求澄清、模块分析与拆分、协同开发、真实验证、MR 迭代、合入交付。
- **知识自闭环**：交付复盘产生草稿，整理并经人审视后入库，按需检索进入下一次开发；组件知识缺口通过源码与跨仓用例补充。
- **设计思想**：人掌方向，流程为质量与速度服务，经验反复复用，方法和系统易于维护。

「一键播放」约 40 秒，共 12 段，带路径流动、高亮、自动缩放聚焦和右侧弹出讲解卡。每段讲解说明具体做法、原因与例子；底栏只放提要，不因加快播放而删减正文。讲解卡有独立空间，不遮住图，长正文可滚动。鼠标移入正文或键盘聚焦正文会暂停，点击「继续」恢复。可以暂停、继续、前后切换；手动放大/缩小会暂停自动推进，点击「全景」恢复整图。自动聚焦最多 170%，手动可放大到 250%。点击任意模块查看职责。空格播放/暂停，方向键切换讲解，Esc 返回全景（焦点在交互控件时优先保留控件的按键行为）。切离页面会暂停；开启系统减少动态效果时保留讲解及聚焦、关闭过渡动画。

这是能力架构，不是强制串行的阶段流程。知识草稿不会未经审视自动成为团队约定，普通知识检索也不会自动触发源码萃取。演示不展示虚构业务指标，不包含生产任务、凭据或内网地址。

## 文件与构建

- `mae-flow.architecture.json`：原生 Archify 语义、节点、关系与布局数据。
- `architecture.svg`：可直接放入材料的静态矢量图。
- `index.html`：包含所有样式、图和脚本的单文件交互演示；可复制到其他电脑。
- `presentation.template.html` / `presentation.css` / `presentation.js`：展示层和讲解交互。
- `build.mjs`：调用仓库内原有 Archify 渲染器，再封装演示外观；临时文件在结束时清理。

构建同时同步 `web/public/help/platform-overview/` 下的 HTML/SVG，正常前端构建自动带入发布包；维护时修改本目录源文件并运行下面的构建命令，不手工修改两份生成资产。

仓库根目录执行：

```bash
node docs/showcase-2026-09-21/build.mjs
python3 -m http.server 8860 --bind 127.0.0.1 --directory docs/showcase-2026-09-21
```

访问 `http://127.0.0.1:8860/`。「导出图」导出当前架构的完整 SVG，自动移除交互中的淡化与动画。
