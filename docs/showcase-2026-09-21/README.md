# MAE Flow 对外架构演示

打开 `index.html` 即可离线演示，无需登录、安装依赖或连接生产服务。推荐 Windows 桌面浏览器 1920×1080，点击「全屏」。

平台入口：**使用帮助 → 顶部「一分钟看懂：交付与知识双闭环」→ 一键播放**。新页面自动开始；「查看架构」只打开全景，不自动播放。地址为 `/help/platform-overview/index.html`，加 `?autoplay=1` 自动讲解。

## 怎么讲

- **全景架构**：一张图呈现交付闭环、知识闭环和工程能力底座。
- **交付视图**：独立架构图，按分析开发、首次交付、MR LOOP、合入回流四个能力域展开；展示提交 MR、流水线修复、检视意见汇入、人判断与批量分派、修复提交和复验。
- **知识视图**：独立架构图，按生产、治理、外部存储与获取、RAG 消费四个能力域展开。三类生产是交付复盘、基础组件萃取、团队资料与源码治理；公共 Git 仓承载 Markdown，导入后分节、建索引、按需消费。
- **设计思想**：人掌方向，流程为质量与速度服务，经验反复复用，方法和系统易于维护。

「一键播放」约 46 秒，共 14 段，带路径流动、高亮、自动缩放聚焦和右侧弹出讲解卡。每段讲解说明具体做法、原因与例子；底栏只放提要，不因加快播放而删减正文。讲解卡有独立空间，不遮住图，长正文可滚动。鼠标移入正文或键盘聚焦正文会暂停，点击「继续」恢复。可以暂停、继续、前后切换；手动放大/缩小会暂停自动推进，点击「全景」恢复整图。自动聚焦最多 170%，手动可放大到 250%。点击任意模块查看职责。空格播放/暂停，方向键切换讲解，Esc 返回全景（焦点在交互控件时优先保留控件的按键行为）。切离页面会暂停；开启系统减少动态效果时保留讲解及聚焦、关闭过渡动画。

这是能力架构，不是强制串行的阶段流程。知识草稿不会未经审视自动成为团队约定，普通知识检索也不会自动触发源码萃取。演示不展示虚构业务指标，不包含生产任务、凭据或内网地址。

## 文件与构建

- `mae-flow.architecture.json` / `delivery.architecture.json` / `knowledge.architecture.json`：三张原生 Archify 图的节点、关系与布局。
- `module-details.json`：每个小能力的职责和边界。
- `architecture.svg` / `delivery.svg` / `knowledge.svg`：三张可直接放入材料的静态矢量图。
- `index.html`：包含所有样式、图和脚本的单文件交互演示；可复制到其他电脑。
- `presentation.template.html` / `presentation.css` / `presentation.js`：展示层和讲解交互。
- `build.mjs`：调用仓库内原有 Archify 渲染器，再封装演示外观；临时文件在结束时清理。

构建同时同步 `web/public/help/platform-overview/` 下的 HTML/SVG，正常前端构建自动带入发布包；维护时修改本目录源文件并运行下面的构建命令，不手工修改两份生成资产。

仓库根目录执行：

```bash
node docs/showcase-2026-09-21/build.mjs
python3 -m http.server 8860 --bind 127.0.0.1 --directory docs/showcase-2026-09-21
```

访问 `http://127.0.0.1:8860/`。「导出图」导出当前视图的完整 SVG，自动移除交互中的淡化与动画。

## 2026-09-22 多视图扩展

交付与知识页签现在切换独立布局，不再只是高亮全景图。大框表示能力域，小框表示具体能力，点击小框查看职责；详情独占侧边空间，保持图可读。14 段讲解自动切图、聚焦，可暂停阅读；导出随当前视图切换。支持 `?view=delivery` / `?view=knowledge` 直达。
