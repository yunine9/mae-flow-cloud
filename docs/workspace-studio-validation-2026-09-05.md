本轮按用户确认原型实现，视觉验收以实际预览为准。入口：`http://localhost:8838/work/task-8`、`/work/task-5`。

## 已实现

- 左侧为完整材料工作区；过程文档使用目录 + Markdown 阅读器，代码默认展示文件树与差异分栏。
- 右侧优先展示当前决定/异常，其后是反馈与 Agent 回应。回复和提交通过 portal 固定在同一协作栏底部，使用原本的组件状态与权限判断。
- 运行中补充输入和开发助手使用同一底部区域；待决定时只有决定回复是主入口，高级协作保留为次要展开项。
- 单问题卡将备注和自由答复合为一个输入框，明确选择的分支优先；取消选项后文本成为自由答复。多问题与需求确认维持原有专用流程。

- 普通反馈提交不会自动决定返工/推送；全屏检视保留显式标注的提交并返工快捷动作。最终放行、版本清单绑定、排队和中断语义继续由原 API 决定。
- 去除重复失败描述、零反馈筛选条、普通视图的第三个抽屉。保留邀请、搜索、下载、全屏、依赖图、原始事件和任务控制。
- 浅/深主题、长代码换行、窄屏目录、行内编辑器边界、底部遮挡和可见键盘焦点有独立处理。
