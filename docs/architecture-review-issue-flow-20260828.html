  • 注册表即可测接口

Top recommendation

先做候选 1:阶段注册表

阶段是问题流的主轴,也是近两天改动最密集的地方(放宽工读门禁、收嘴/催办、多仓平铺、计划线改版——四次全部横跨 state/prompt/tools/service 四个文件)。把阶段收成一张注册表,是当前所有阶段演进的单点地基:引导/权威漂移从这里根治,"出口/催办"已有实现直接受益,你提过的"进入阶段必调技能"就是表上加一列。纯后端、无 UI 依赖、测试模式现成(工具直调 + 裸仓端到端都是现成的),一天到一天半的改造面。

第二顺位:候选 5(DTS 消毒,半天,安全优先级)+ 候选 3(一仓一 MR 上屏,ADR 的 UI 落实,用户价值最直接)。候选 4/6 属于"下次大改前顺手",候选 2/7/8 可组合进任意一次相关改动,不必单开战役。

评审豁免注记:capAnalysisText 与 prepareSandbox 的两处刻意重复(跨域不 import 纪律,注释自证)不列为候选;sessionView.ts 与 worksiteExport.ts 是域内深模块标杆。工作区另有未提交改动正在演进(ADR-0001 后续),行号以评审时点为准。
