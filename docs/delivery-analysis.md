# 交付分析

页面保留“交付代码行数”“首次提交占比”和代码来源分布，总览、任务表及详情均不再展示“累计修改行数”。

入口为侧栏“交付分析”，代码改动页也提供当前任务入口。需求数据已接入；问题处理保留入口，暂不参与需求统计。

## 数字口径

- **交付代码行数与来源**：合入的源版本相对合入前目标分支共同祖先的 diff 中，新增及修改后的文本行。逐行使用 Git blame 查最后修改提交；首次提交占比 = 其中源自首次提交的行数 / 全部最终新增及修改行数。不是“首次提交有多少没被删”的留存率，也不是编译通过率。
- **首次提交**：任务创建基线之后，源分支第一父链上的第一个非合并提交。即使该提交只含文档，也不换成后来的代码提交。
- **内部提交增删记录（页面不再展示累计修改指标）**：首次提交之后，非合并提交的代码新增行数 + 删除行数。改一行计两行，多次修改重复计数。此值和最终代码分母不同。纯重命名为零。合并提交中的冲突解决暂不计入返工，避免把引入的上游变化当成返工。
- **分类**：首次提交单列；后续提交有流水线反馈、CI 修复轮次或提交说明中明确的 CodeCheck、编译失败、覆盖率修复等线索，就归流水线修复；其余全部归检视意见修改。没有“其他”“混合”“未归因”。已有历史区间和推送记录继续作为识别依据，提交说明作为补充；两类线索并存时流水线优先。旧统计中的其他项自动并入检视修改。
- **口径**：检视意见修改是非首次、非明确流水线修复的剩余修改，不代表每个提交都有一条真实人工意见。提交明细保留分类依据，推断与平台记录可区分。代码行数仍由 Git 计算。

- **范围**：代码扩展名白名单覆盖 C/C++、Java、JS/TS、Python 等源码、测试、SQL、Shell 及样式；文档、配置、锁文件、二进制、常见生成目录及生成文件名不在分母。并非所有仓库的自定义生成物都能自动识别；白名单在 `src/deliveryAnalyticsGit.ts`。删除行另计，不装进最终保留代码。
- **团队汇总**：仅纳入已完成且 MR 已合入、最终源 SHA 与采集快照一致的任务。按行数加权，不平均各任务百分比。主任务显示“子任务汇总”，指标聚合当前筛选范围内的子任务，状态显示已合入子任务数（含未合入数据时标为暂计），不表示主任务自身交付代码；团队汇总仅计实际交付任务一次，未拆分且直接交付的任务正常展示。时间按合入完成时间。squash / rebase 合入产生的目标 SHA 无需等于源 SHA；统计的是已确认推送的源版本，不将合入提交当作源版本，也不代表 squash 时额外修改的目标代码。

## 取证和运行

宿主确认推送事实后调用 `recordDeliveryPublication`，先在统计文件保存当轮起点、终点及来源，再异步调用 `observeDeliveryCode`。统计失败不会丢失已记录轮次；重启后页面采集可使用所有保存区间重算。历史任务可从现存 `.mae-flow.json` 的反馈批次补算，仅读取，不调用内核或增加流程判定。所有统计读 Git 都异步执行、全局单工作槽、单任务有提交数/文件数/输出/时间预算，不 fetch、不改工作树、不参与任何推进/审批/合入判断。恢复记录和页面读取也能触发缺失快照采集；失败不会重派 Agent。修复证据、内核现场文件变化或旧版缓存会自动触发更新；页面“刷新数据”可重算已有快照及重试失败的取证。同一源版本重算保留合入前基线，避免目标分支推进后把已有数字清空。工作区已回收时保留已有数字，但无法重新归因。

快照原子保存在任务目录旁 `.delivery-analysis/<任务与工作区哈希>.json`，不在 Agent 挂载目录内；采集失败保留上一份快照用于后续历史追踪，但不同版本的旧数字不会展示成当前结果。备份任务数据时需一起备份该目录。工作区回收不删除统计快照。

历史任务若没有合入前快照，且本地目标已经包含源提交，显示缺少证据，不从空 diff 得出 0%。首次采集前已有外来提交、提交历史被改写、对象缺失或超过预算时同样显示原因，不进入正式数字。历史原因记录缺失会降低分类覆盖，缺失部分使用有明确线索的规则推断，不调用模型。

接口 `GET /delivery-analytics` 与团队任务使用同一登录可见范围；普通成员可读。`?refresh=1` 重新触发后台采集，请求本身不等待 Git。前端展示覆盖任务数，未知不是零。

```bash
npx tsx --test tests/deliveryAnalytics.test.ts
npm run gate
npx tsx scripts/seed-delivery-analysis-demo.ts
MAE_FLOW_UI_FIXTURE_MODE=1 npx tsx src/serve.ts --data .e2e-fixtures/delivery-analysis --port 8851
```

演示脚本只创建不存在的本地专用目录，包含真实 Git 首次提交、CI 修复、人工检视修改、未归因修改及缺证据任务，直接调用正式统计器。打开 `http://127.0.0.1:8851/?deliveryAnalysis=1`，本地演示账号 `admin / mae-flow-demo`。不要将演示账号用于正式服务。
