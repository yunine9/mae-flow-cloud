# 环境管理:全局台账、IP 唯一、选入即快照

2026-09-09 拍板,新增「环境管理」模块(全局维护的网管环境台账),终结每次补环境全手输的重复:①一条记录一个环境,以 IP 为唯一键;字段为部署形态、端口、sopuser 三账号后台密码、可选独立 root 密码、自定义标签数组、探活状态。页面凭据不入台账,仍在登记页手填。②root 密码数据层恒有有效值(表单非必填,留空=与 sopuser 相同,placeholder 引导)。③全员可读可用可编辑,admin 可管理(环境库是全局资源,不受"管理员不处理问题单"约束),记 updated_by,密码前端永不回显、编辑留空=不变。④后台定期以 sopuser 账号探活,三态(未验证/正常/异常)并区分认证失败/不可达;新增/编辑处的测试连接复用同一探测端点。⑤登记页与 env_needed 闸卡都接「从环境管理选」;闸卡手动回退保留,另加同样语义的可选 root 密码字段。

关键裁定:**选入会话即快照**——选中把值拷进会话 vault(storeEnvironment 原路径),台账后续改动、删除都不影响已进行与历史会话;会话是历史事实,台账是当下状态,两者不耦合,终局清理 vault 的卫生逻辑零改动。hosts[] 是会话侧 wire 预留(state.ts:103),台账模型一条=一个 IP,选入时塞 hosts:[ip]。

曾考虑「引用而非快照」(台账改了会话跟着变),被否:台账编辑会把历史会话的凭据悄悄换掉,排障时对不上当时现场。密码落盘沿用 vault 机制(AES-GCM 加密、不进状态文件,ADR-0003),仅把存储位置从按会话改为全局台账;探活只用 sopuser,root 密码不参与探测。
