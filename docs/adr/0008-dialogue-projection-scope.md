# 过程问答:复盘投影只留问答与用户输入,agent 过程性发言不进

2026-08-31 拍板:过程问答页签是现场记录(events.jsonl)面向复盘的投影,口径为问答对——呈现四类回合:agent 举的问答卡、用户对卡与平台闸的答复、用户的主动插话/续聊、检视意见;agent 的过程性发言(开场白、进度播报、总结陈词)一律不进。平台闸的问句在事件账里没有现成记录,由投影从会话状态里的闸快照合成,保证三个关键决策点(分析确认/无单结论/环境验证)问答对完整——否则只剩用户答复、没有问题,复盘读不懂当初在决策什么。投影只追加、不回写:agent 修订分析报告也不改写已有问答,新事实以新回合出现;events.jsonl 只追加是审计底线,历史对话永不重写、不删除。

理由:复盘的主要噪音是 agent 的过程性发言("开始拉仓""UT 跑完了"),剔掉后剩下的就是决策链:问了什么、答了什么、为什么改主意——最后这条全靠用户自己的原话,所以用户主动输入必须保留。曾考虑最严口径(只留卡与决策,用户插话也剔),被否:信息损失大于噪音收益;全量对话的现状则复盘时读不下去。代价是"agent 当时怎么说的"要去现场页签看——两视图分工明确:现场 = 直播,过程问答 = 复盘,互不替代。
