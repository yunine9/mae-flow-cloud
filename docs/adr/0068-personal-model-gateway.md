# 个人网关:成员自助模型接入,Beta 网关退役

2026-10-30 拍板。推翻 ADR-0039 对「用户自助自带 API」的否决:成员在个人设置自助配置模型接入(地址/密钥/模型/接口格式,四字段同平台网关),配齐即整体生效——该成员名下任务的全部主模型调用走个人网关。Beta 网关(admin 托管的白名单通道)整体退役删除,按人换通道的职责由个人网关接手。

**理由**:ADR-0039 否决自助方案时的三个坑,现逐个消解——key 明文扩散:落进任务现场的是用户自己的 key、自己的现场,信任边界较 admin key 落 N 个现场没有变差,0600 与现场回收纪律照旧;账目:token_usage 与 model_lane 留痕机制 ADR-0039 已建,个人通道烧自己的 key,通道名记清即可;闸门:个人开关本身就是闸门,无需总开关。ADR-0039 当时即预留口子(「解析函数多认一个按人输入即可,两案不冲突,到时再议」),本 ADR 兑现该口子。Beta 网关的信任模型是「key 交 admin 托管」,成员真有更好模型时摩擦大;个人网关让通道跟人走。代价:admin 失去「圈部分人试新模型」的工具——要换模型要么全员切平台网关,要么成员自配。

**口径**:
- **覆盖**:个人网关命中 = 该成员名下任务的全部主模型调用(主会话/修复/预热/摘要/记忆起草/skill 提炼/prepush/开发助手/知识问答,需求与问题两条流同管),整体替换;任务级 model_choice 让位(同 Beta 旧例);识图(vision)与无归属的后台调用(视觉自检、领域/组件研究)仍走平台网关——后者解析时没有归属人,前者量小且平台视觉配置是全局资产。
- **生效条件**:四字段配齐才生效,缺任一视同未配,静默回落平台网关并记一行日志(同 Beta 解析级 fail-open);不做字段级合并——一套配置一套账。清空即回落。运行级故障不做会话中途换道,该回合按现有失败路径处理,下次会话启动现算重新解析(同 Beta 旧例)。
- **解析时机**:会话启动现算,配置变更下回合生效,不进任务级 model_choice 的下单冻结,进行中会话不追溯。
- **密钥**:照个人令牌先例(Git/小鲁班 Token)——明文住 0600 用户表,接口只写不读、只回末 4 位掩码,留空=沿用;admin 与普通用户同视角,看不到他人完整密钥;个人设置带连通性测试(复用网关检查的草稿合并逻辑)。
- **权限**:全员可用,无 admin 总开关。
- **解析口子**:照 ADR-0039 预留方案,resolveModelConfig 多认一个按人输入,三个调用点(taskService/issueFlow/知识问答)结构不动。
- **Beta 退役**:配置(models_beta)、白名单、管理页卡片、保存/测试端点、解析分支全删;settings.json 存量 Beta 配置读取时忽略,白名单成员自动回落平台网关;历史任务 model_lane=beta 是事实账,照读不动。
- **留痕**:任务记 model_lane(平台/个人),个人通道消耗看 token_usage 与网关侧账。
