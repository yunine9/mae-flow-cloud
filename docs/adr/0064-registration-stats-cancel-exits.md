# 登记问题统计收紧:取消全退,人群=非问题+确认是问题

2026-10-16 拍板:交付分析「登记问题」页签的统计人群从「研究完成=非问题+确认是问题+取消」(ADR-0048 第三节)收紧为**非问题+确认是问题**。取消从本页签全部数字、瓦片分母、按模块/按登记人分组表(含独立「取消」列)与按会话清单中整体退场。

**理由**:ADR-0048 当初把取消计入「研究完成」分母是有意拍板,但运行下来口径要反转——取消是会话的**退场**(终止、放弃、存量挂起经取消清场),不是研究的一种结论;它计入登记总数与非问题闭环率/确认是问题率的分母,稀释了页签要回答的问题(真实研究结论的构成)。一次定位率早就按「取消不构成一次研究」剔除了(ADR-0048),本次把其余数字统一到同一语义:**取消=退场,不构成研究结论**。ADR-0057 让存量挂起只能经取消退场,这批会话自此按本口径彻底不入登记统计——正是 0057「不入结论统计」的本意。

**连带取舍(拍板)**:页面失去「登记了多少、放弃了多少」的退场信号——取消会话仍可在问题列表/归档查看,登记质量信号让位给口径干净。纯投影零迁移:结论本就在 issue.json,历史比率按新口径自动重算,无起算日。后端投影直接不发取消(`canceled` 计数字段、会话行取消结论、组行取消列全部退役;`localization_pass` 随取消行退场变为必有),前端无过滤逻辑,读侧与端点同一口径、不建第二套。ADR-0048 原文不改(保留历史拍板记录),本 ADR 是其统计口径的修订。

曾考虑:(a) 「取消率」瓦片(取消÷三者和)保留退场信号——否,拍板明确:取消完全不参与统计,不造任何取消衍生指标。(b) 取消只退比率分母、按会话清单保留显示——否,清单行数与瓦片总数不一致会被当缺陷报;本页签不是会话台账。(c) 分组表保留「取消」独立计数列(不进登记数、不进比率)——否,同 (a),退就退干净,按模块看退场的诉求不再服务。
