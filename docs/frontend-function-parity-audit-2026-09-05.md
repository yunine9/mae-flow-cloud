## 相对远端 main 尚未同步的差异

远端比本地 main 新。其前端变化集中在 AnnotationPanel、TaskWorkspace、api；另有服务端配套改动。

1. 批注闭环：远端由服务端 `feedbackPolicy` 返回 `AnnotationClosure`，包括归档分组、文案及可操作权限；当前分支仍在前端推导。不是换皮遗漏，而是主干业务演进未同步，不能仅复制组件或伪造字段来宣称一致。
2. 子任务材料：远端新增 `delivery_unit_brief` / `delivery_plan` 用途、默认当前任务书、任务书优先排序和子任务导航区别；当前仍可查看已有文档，但没有这些新增的专用导航行为。
3. 远端另有交付重试/停摆判定等后端改动。本轮没有合并后端，不声称运行行为与最新 main 完全等价。

后续合并应保留 Studio 布局，同时联动同步这些 API、服务端判定、对应测试与子任务材料导航。
