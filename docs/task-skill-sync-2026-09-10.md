# 在途任务补充团队技能

任务创建时固定技能快照。新发布的技能不会进入旧快照，导致已经运行的任务找不到它。

本次增加「用到的知识 → 补充新技能」和 `POST /tasks/:id/skills/sync`，只允许当前责任人操作：

- 按任务的仓库、技术画像、业务模块匹配新增技能名；已有同名技能保留原版本。
- 使用现有包校验与快照器复制完整技能包，包含脚本和资料。
- 运行中向主 Agent 发送技能路径提示；排队任务随启动提示送达；等待决定的任务随下一次决定送达。
- 辅助会话正在运行而主会话不存在时，补充内容暂存至主会话继续，不声称已热加载到辅助会话。
- 快照装载失败保留待同步名单；消息发送失败保留待发送内容，重试不用重新下单。
- 使用足迹只记「可用」，实际读取仍由正常读取事件登记。

不会自动更新旧技能版本，也不会因新上架技能而打断任务。内网部署新版本后，task-17 的责任人可直接从知识页补充 activity-center，不必手改快照或重新下单。

同次修复：检视意见的「确认通过」直接提交人工结论，说明选填，不因缺 Agent 回执额外索要理由。责任人权限、版本核对保留；不采纳、延期和接受风险仍需说明原因。人工结论与 Agent 回执分别记账。

验证：新增 4 个技能同步测试覆盖全包、旧版本保留、范围匹配、排队、运行中发送、失败重试、等待决定及权限；闭环服务测试覆盖需求原文、代码和设计文档的空说明确认；相关批注、技能和 UI 回归通过。浏览器验证知识入口和回执展示、空说明保存按钮可用、直接确认发出 fixed/空 reason 请求（拦截响应避免改变预览数据）。未连接内网 task-17 做部署验收。
