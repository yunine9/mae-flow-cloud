# 万马奔腾：MAE Flow 核心展示

## 参赛范围与主线

作品主角是 MAE Flow 的核心 Harness，即围绕 Agent 组织工作方法、执行工具、过程状态和人工决定的工程支撑。MAE Flow Cloud 是这套思路的宿主和演示现场，不把整个 Cloud 平台的功能都纳入十分钟讲解。

主线：**用可靠、易改、够快的代码，打造真正好用的工程工具。** 四个评选导向用具体设计取舍说明，不用功能数量、代码规模或开发时长证明优劣。

## 使用方式

PowerPoint 用于口述架构和设计取舍，浏览器用实际记录支撑判断。幻灯片逐页备注包含讲述提示。`slides/` 为六页静态备份，可以在现场字体或投屏异常时直接打开。

构建源是 `build.mjs`，使用 `@oai/artifact-tool`。需要提供 `RUNTIME_NODE_MODULES`、`RUNTIME_PYTHON`、`SKILL_DIR` 与独立的 `BUILD_DIR`，输出写入本目录，用 `DECK_NAME` 指定新版本的文件名。生成脚本不读取生产数据、不修改平台代码、不启动服务。构建缓存位于忽略的 `node_modules/.cache/mae-flow-competition`，验证结束后清理，不创建 UI fixture。
