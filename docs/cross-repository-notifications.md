# 同一需求的协作通知

任一子任务发出的通知，都记入主任务、发送任务及全部兄弟子任务。
投递按 parent_task_id 归属计算，不依赖依赖图的边或仓库节点映射。
不同主任务之间不广播。

- 正在运行：消息进入 Agent 插话队列，当前工具调用结束后读取；运行中的主任务也收到。
- 排队：只记录消息，不改变 blocked_by、队列顺序或启动时机；正常启动时读取完整历史。
- 暂停或等人：保留消息，继续运行或提交答复时读取。
- 已完成或取消：保留通知记录，不重新启动任务或恢复已回收的工作区。
- 后创建：继承已有通知。服务恢复时合并父子任务台账，补齐旧版空目标和部分落盘记录，按消息 ID 去重。

历史不再被最后 5/10/30/100 条的限制截掉。Agent 从实际工作目录的
`.mae-flow-work/cross-repository-updates.md` 读取完整内容；prompt 指向
真实绝对路径。投影文件不可写时直接附上完整文本，不阻塞继续执行。
通知只要求判断影响：无关继续、已处理无需重做，确有歧义才提问，
不改变依赖调度或工作范围，也不引入新的确认卡和门禁。

本地验证覆盖无依赖边广播、任意兄弟节点发送、排队依赖不变、
真实模型读取完整记录、暂停与终态不启动、后来创建、重启补收、
投递失败隔离及工作台展示。已被旧版从所有台账删除的历史无法恢复。
