# 保存与修订

先按 mode 和当前任务说明确定修订范围，再按 schema.md 保存字段，component_work_result 提交本轮结果。task.id 为 whole-review 或 supplement 的任务虽使用 phase=inventory，仍执行本文的修订规则；它们无需模块盘点文件。指南正文、调用证据、测试证据和研究问题各归其字段，平台生成完整指南与派生数据。

讨论只回答当前问题。修订和增量更新先读取当前章节，围绕选中范围重新核对源码、实际调用和 UT，保留人工已确认内容；适用版本变化时同步更新 evidence、usage_evidence、test_evidence 和适用条件。

whole-review 先读取全部现有文稿，再依据整体意见修改概述、修订已有章节或新增有依据的章节。已有章节沿用原编号；新增章节采用新编号，按其 kind 读取对应阶段规则。概述继续遵循两个固定二级区块，保持与章节内容一致。

supplement 先读取现有目录，再用新编号补充确实缺失的使用场景，保留已有章节与概述。没有代码支持的线索写 open_questions。

完成条件是修改范围清楚、字段与正文一致、证据可回读。修订作为待采纳建议交给用户，正式知识发布和规则启用分别遵循用户决定。
