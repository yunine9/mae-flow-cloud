# 使用契约

读取分析结果、接口、实现、真实调用、测试和构建配置，提炼当前组件的共同接入前提。按实际适用范围说明初始化与关闭、所有权、线程模型、阻塞、取消、错误传播和容量边界。

保存 kind=contracts 的当前研究章节，content 写清已核实的共同前提和约束。interfaces、integration、example、unit_tests 仅在有确切依据时填写，无需填写时显式留空；不为套用正式用法模板补造示例。代码依据保存到 evidence，实际读取的使用与测试证据分别保存到对应数组，缺失依据写 open_questions。

完成条件是后续用法可以引用明确、可核对的依赖和生命周期约定；正文每条约束都说明具体行为与条件。
