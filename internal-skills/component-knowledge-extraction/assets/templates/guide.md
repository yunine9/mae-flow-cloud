# 最终组件指南结构

平台将当前技术栈中已确认的功能组件用法组合为一份指南，按以下层级生成标题：

- 技术栈组件知识：整篇文档标题。
- 组件用途：按文件操作、数据库操作、P2P 等实际能力说明解决的问题与适用对象。
- 接入配置：分别说明各功能组件的依赖、构建目标、配置和初始化前提。
- 用法导航：开发目的、对应场景与适用条件。
- 各项用法：依次展示适用场景、关键接口、使用步骤、完整示例、单元测试示例、使用约束；有确证条目时追加常见误用。

overview 只保存组件用途和接入配置；每项用法的独立字段按 schema.md 保存。功能组件由模块分析结果确定，可跨仓实现。导航和目录由程序生成，章节正文围绕实际使用展开，来源与研究记录保存在元数据。
