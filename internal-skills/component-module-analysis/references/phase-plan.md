# 开发场景规划

读取当前模块的盘点结果与源码，分别展开 everycode 的真实调用和单元测试。沿使用目的、调用前提、生命周期和结果处理比较差异，继续读取相关 fixture、断言与 helper。

把能独立讲清的开发需求规划为 paradigms 的 id、title、need。初始化、调用、错误处理和清理通常是同一完整用法的步骤；前提或行为确实不同的场景再分开。

完成条件是每个场景都有真实代码线索、明确需求及后续要回答的问题，模块的主要使用方式得到覆盖。findings 保存场景边界和证据起点，open_questions 保存尚缺的依据；运行预算或读取范围不足时如实说明覆盖边界。
