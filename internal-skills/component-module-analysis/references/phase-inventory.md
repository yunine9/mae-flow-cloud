# 模块盘点

综合当前技术栈的参考源码，读取实际入口、实现、构建与测试，用 everycode 展开调用及相关测试。按功能能力识别组件，例如文件操作、数据库操作、P2P；这些是能力粒度的例子，具体清单以代码事实为准。合并跨仓共同实现的同一能力，同仓的不同能力分别列出。

用 components 的 id、title、repository_ids、scope 提交目录；确有能力依赖时给 dependencies，指向目录内模块。findings 保存形成目录的代码依据、已查范围与候选处理结果。

完成条件是目录覆盖已发现的独立开发能力，每项有具体用途、跨仓代码起点与相邻能力边界。参考仓编号只说明代码来源，组件编号独立表达能力；同一用途的协作函数合并，待确认问题列入 open_questions。
