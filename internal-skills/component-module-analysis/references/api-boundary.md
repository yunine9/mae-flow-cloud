# 分析能力边界

以使用团队实际需要的能力为单位，结合接口、实现、构建发布、真实调用及测试分析。目录名、公开可见性和调用次数分别是线索，支持结论还需读取代码。

关注实际 SDK 门面、interface、idl、include、api 或 exports；存在 sdk/pom.xml 时读取聚合与子模块配置，追踪依赖、profile 和发布条件。其他构建系统按真实配置核对。协议定义继续定位生成入口及产物。

内部 helper、fixture、mock 和实现类可说明模块行为与测试条件。模块目录说明其作用与边界；后续使用指南采用受支持入口，测试设施保留在对应测试语境。

开发能力可能由多个函数共同完成。按使用目标与前提归组，覆盖相邻能力之间的依赖；候选范围或发布属性未确认时保留具体问题及代码线索。
