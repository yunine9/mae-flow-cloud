## 七、自动生成

规划通过独立核查后无需用户确认，登记完整文档清单对应的写作与评审说明，再用 knowledge_work run 省略 id 推进。按真实依赖组织，无依赖且写入范围不交叉的单元默认最多三个并行；每个文稿仍先写作再独立评审。全部适用文稿最新版本通过且导航一致后才能报告完整完成；原始证据缺口如实记录。
