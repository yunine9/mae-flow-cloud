# 默认归档位置

平台读取以下配置，为首次萃取生成逻辑文档目录，并在「入库与更新」带出建议值。管理员可以通过 Skill 编辑器修改。它们是默认值，归档时用户可以覆盖；已有任务的目录和 MR 不随默认值变化。

```json
{
  "domain_directory": "domains",
  "repository_directory": "docs/knowledge"
}
```

领域知识默认归档到平台配置的知识仓；各业务仓知识默认回到对应源码仓和研究分支。平台没有配置领域知识仓时，先正常生成草稿，归档时再选择仓库。不能因为归档位置尚未选择而中断研究。

萃取时按平台给出的逻辑根目录组织文档。平台确认归档位置后会映射文档路径，并重新比较目标位置的已有内容。源码仓和归档仓是两类输入，更换归档位置不会改变后续核对源码的范围。
